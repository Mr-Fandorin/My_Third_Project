# Проект "Виджет банковских операций клиента"

## Описание:

Проект "Виджет банковских операций клиента" - это веб-приложение на Python для работы с персональными данными клиента. 

## Основная функция проекта, которая объединяет все дополнительные функции для отдельных операций.

С помощью функции **main** можно получить полную информацию по банковским операциям по запросу пользователя.


## Маскировка номеров карт и номеров счета:

С помощью функции **mask_account_card** номер карты/счета маскируется:
```
### Пример для карты
Visa Platinum 7000792289606361  - входной аргумент
Visa Platinum 7000 79** **** 6361  - выход функции
```

```
### Пример для счета
Счет 73654108430135874305  - входной аргумент
Счет **4305  - выход функции
```

## Функция вывода даты

С помощью функции **get_date** можно вывести дату в упрощенном виде.
```
### Пример для даты
2024-03-11T02:26:18.671407 - входной аргумент
11.03.2024 - выход функции
```

## Функция фильтрации списка словарей с данными:

С помощью функции **filter_by_state** происходит фильтрация списка словарей по ключевому параметру (по умолчанию "EXECUTED")
```
### Пример фильтрации

* Вход
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]

* Выход функции со статусом по умолчанию 'EXECUTED'
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]

* Выход функции, если вторым аргументов передано 'CANCELED'
[{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
```
## Функция сортировки списка словарей с данными:

С помощью функции **sort_by_date** происходит сортировка списка словарей по ключу 'data' (по умолчанию сортировка идет по убыванию)
```
### Пример фильтрации

* Вход
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]

* Выход функции (сортировка по убыванию, т. е. сначала самые последние операции)
[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}, {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]
```

## Функция, которая загружает информацию из файла json и выводит список словарей с данными:

С помощью функции **operations_data** можно получить информацию из json файла, преобразовав ее в список словарей для Python.


## Функция, которая производит конвертацию суммы транзакции в рубли:

С помощью функции **exchange_amount** можно произвести конвертацию суммы транзакции из другой валюты в рубли.


## Функция, которая загружает информацию из файла csv и выводит список словарей с данными:

С помощью функции **reader_csv_transactions** можно получить информацию из csv файла, преобразовав ее в список словарей для Python.


## Функция, которая загружает информацию из файла excel и выводит список словарей с данными:

С помощью функции **reader_excel_transaction** можно получить информацию из excel файла, преобразовав ее в список словарей для Python.


## Функция, которая осуществляет поиск транзакций по ключевому слову в категории 'description':

С помощью функции **process_bank_search** можно по поисковому слову вывести список необходимых транзакций.


## Функция, которая осуществляет подсчет транзакций по запрашиваемым категориям из раздела 'description':

С помощью функции **process_bank_operations** можно подсчитать, сколько транзакций было произведено по запрашиваемой пользователем категории.


## Модуль генераторов (generators.py)
### Генератор функции сортировки базы данных по заданной валюте:

С помощью генератора **filter_by_currency** происходит фильтрация базы данных по ключу 'code' (наименование валюты)


### Генератор функции вывода описаний транзакций:

С помощью генератора **transaction_descriptions** происходит вывод описаний транзакций из базы данных по ключу 'description'

### Генератор номеров карт в заданном диапазоне:

С помощью генератора **card_number_generator** происходит генерирование номеров карт в указанном диапазоне.
```
#### Пример фильтрации

* Вход
Диапазон от 1 до 5

* Выход номера карт:
0000 0000 0000 0001
0000 0000 0000 0002
0000 0000 0000 0003
0000 0000 0000 0004
0000 0000 0000 0005
```

## Блок тестирования / tests:

### test_masks

Произведено тестирование модуля masks.py для проверки работы функции маскировки номеров карт и счетов. 
Учтены различные варианты ввода (больше/меньше цифр, пустой ввод)

### test_widget

Протестированы различные вводы полных данных карт и счетов. Отработаны различные варианты ввода неполных, некорректных данных.
Также протестирована функция вывода даты **get_date** на предмет ввода дат в различном формате.

### test_processing

Отработано тестирование фильтрации и сортировки списка данных.

### test_utils 

Отработано тестирование загрузки данных из файла json.

### test_external_api

Отработано тестирование конвертации валют в рубли.

### test_generators 

Отработано тестирование генераторов.

### test_decorators  

Отработано тестирование декоратора.

### conftest

Сформирован отдельный модуль для фикстуры.
